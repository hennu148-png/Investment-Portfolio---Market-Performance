# 📊 Investment Portfolio and Market Performance Dashboard

## 📌 Project Overview

The **Investment Portfolio and Market Performance Dashboard** is an interactive data analytics dashboard designed to monitor, analyze, and visualize investment portfolio performance.

The dashboard provides a comprehensive view of portfolio metrics, asset allocation, sector distribution, stock holdings, volatility, returns, portfolio ratings, and recommended actions. It helps investors and analysts quickly understand portfolio performance and make data-driven investment decisions.

---

## 🎯 Objectives

- Track overall investment portfolio performance.
- Compare portfolio performance against a benchmark.
- Analyze current asset and sector allocation.
- Identify top-performing and underperforming holdings.
- Monitor portfolio volatility and return distribution.
- Evaluate portfolio risk and analyst ratings.
- Provide actionable investment recommendations.
- Present complex financial data through an easy-to-understand dashboard.

---

## 📈 Dashboard Features

### 💰 Key Portfolio Metrics

The dashboard displays important portfolio KPIs such as:

- **Total Portfolio Value**
- **Total Daily P&L**
- **Risk Score**
- **Analyst Rating**
- **Total Benchmark Value**
- **Total Quantity**

### 📊 Portfolio Performance

The performance chart compares the portfolio against its benchmark over a one-year period, helping users understand how the portfolio is performing relative to the market.

### 🥧 Current Asset Allocation

A donut chart visualizes the portfolio's allocation across different asset classes, providing a quick overview of portfolio diversification.

### 🏢 Current Sector Allocation

The sector allocation chart shows the distribution of investments across different market sectors and highlights areas with higher portfolio exposure.

### 📈 Volatility Comparison

The volatility comparison section evaluates the volatility of different portfolio types, helping users understand the relative risk associated with each portfolio strategy.

### 🏆 Top 6 Holdings

Displays the six largest/high-performing holdings based on:

- Sum of Daily P&L
- Average Return %
- Portfolio Position Value

### 📉 Bottom 6 Holdings

Highlights underperforming holdings and provides insights based on:

- Daily P&L
- Average Return %
- Position Value

### 📊 Return Distribution

The return distribution chart compares different portfolio types such as:

- Aggressive
- Balanced
- Growth
- Income
- Retirement

### 💡 Action Recommendation

The dashboard provides suggested portfolio actions such as:

- **Buy**
- **Hold**
- **Sell**

This section supports investment decision-making based on portfolio analysis.

### ⭐ Portfolio Rating Overview

A portfolio rating visualization provides an overall view of portfolio quality across different rating categories.
